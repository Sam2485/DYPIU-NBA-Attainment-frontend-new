  • Endpoint: POST /api/v1/academic/director/setup-progress (or PUT          
  /api/v1/academic/director/setup-progress)                                  
  • Optional Query Parameters:                                               
      • ?schoolId=sch-soe (or ?id=sch-soe)                                   
      • ?step=2 (or ?currentStep=2)                                          
      • ?completedStep=school                                                
                                                                             
  ──────                                                                     
  #### • Request JSON (Body):                                                
                                                                             
  All fields in the body are optional; the backend supports updating via JSON
  body, query parameters, or both.                                           
                                                                             
    {                                                                        
      "schoolId": "sch-soe",                                                 
      "currentStep": 3,                                                      
      "completedStep": "2",                                                  
      "completedSteps": ["1", "2"]                                           
    }                                                                        
                                                                             
  Supported aliases/payload variations:                                      
                                                                             
  • step or currentStep (integer: 1 to 4)                                    
  • completedStep (string or integer: "1", "2", "school", "department",      
  "programme", "review")                                                     
  • completedSteps (array: ["1", "2"] or ["school", "department"])           
  • schoolId or identifier (string: "sch-soe")                               
  ──────
