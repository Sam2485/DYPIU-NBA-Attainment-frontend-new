  Database Schema Specification                                             
                                                                             
  This project uses PostgreSQL managed through Flyway migrations (V1 through 
  V3). Below is the complete relational schema of all database tables        
  reflecting the current domain architecture:                                
                                                                             
    School longrightarrow Department longrightarrow MasterProgramme          
  longrightarrow ProgrammeBatch longrightarrow ProgrammeBatchCourse          
  ──────
