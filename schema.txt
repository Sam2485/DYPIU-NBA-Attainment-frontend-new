 Database Schema Specification                                                                                                                                                                       
                                                                                                                                                                                                       
  This project uses PostgreSQL managed through Flyway migrations (V1 through V5). Below is the complete relational schema of all 43 database tables, grouped by domain.                                
  ──────                                                                                                                                                                                               
  ## 1. Academic Hierarchy & Organizational Scope                                                                                                                                                      
                                                                                                                                                                                                       
  ### schools                                                                                                                                                                                          
                                                                                                                                                                                                       
  Stores the top-level institutional school entities (e.g., School of Engineering).                                                                                                                    
                                                                                                                                                                                                       
   Column                                          │ Data Type                                       │ Constraints & Defaults                         │ Description
  ─────────────────────────────────────────────────┼─────────────────────────────────────────────────┼────────────────────────────────────────────────┼────────────────────────────────────────────────
   id                                              │ VARCHAR(50)                                     │ PRIMARY KEY                                    │ Unique school identifier (e.g., sch-soe)
   code                                            │ VARCHAR(20)                                     │ NOT NULL, UNIQUE                               │ School code (e.g., SOET)
   name                                            │ VARCHAR(255)                                    │ NOT NULL                                       │ Full school name
   director_id                                     │ BIGINT                                          │ UNIQUE                                         │ User ID of the assigned Director
   director_name                                   │ VARCHAR(255)                                    │ NULL                                           │ Name of the Director
   director                                        │ VARCHAR(150)                                    │ NULL                                           │ Alternate director label
   director_email                                  │ VARCHAR(150)                                    │ UNIQUE                                         │ Director official email address
   est_year                                        │ VARCHAR(10)                                     │ NULL                                           │ Establishment year
   created_at                                      │ TIMESTAMPTZ                                     │ DEFAULT CURRENT_TIMESTAMP                      │ Record creation timestamp
   updated_at                                      │ TIMESTAMPTZ                                     │ DEFAULT CURRENT_TIMESTAMP                      │ Last updated timestamp
  ──────

   updated_at                                      │ TIMESTAMPTZ                                     │ DEFAULT CURRENT_TIMESTAMP                      │ Last updated timestamp

   Column                                    │ Data Type                                │ Constraints & Defaults                   │ Description
  ───────────────────────────────────────────┼──────────────────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────────────────────────
   id                                        │ BIGSERIAL                                │ PRIMARY KEY                              │ Auto-incrementing user ID
   username                                  │ VARCHAR(100)                             │ NOT NULL, UNIQUE                         │ Unique username for login
   email                                     │ VARCHAR(150)                             │ NOT NULL, UNIQUE                         │ Official email address
   password_hash                             │ VARCHAR(255)                             │ NOT NULL                                 │ BCrypt encrypted password
   name                                      │ VARCHAR(150)                             │ NOT NULL                                 │ Full Name
   role                                      │ VARCHAR(50)                              │ NOT NULL                                 │ Role (DIRECTOR, HOD, PROGRAMME_COORDINATOR, FACULTY, IQAC, ADMIN)
   department                                │ VARCHAR(255)                             │ NULL                                     │ Department name label
   programme                                 │ VARCHAR(255)                             │ NULL                                     │ Programme name label
   school_id                                 │ VARCHAR(50)                              │ FK -> schools(id) ON DELETE SET NULL     │ Assigned School scope
   department_id                             │ VARCHAR(50)                              │ FK -> departments(id) ON DELETE SET NULL │ Assigned Department scope
   programme_id                              │ VARCHAR(50)                              │ FK -> programmes(id) ON DELETE SET NULL  │ Assigned Programme scope

   created_at                                │ TIMESTAMPTZ                              │ DEFAULT CURRENT_TIMESTAMP                │ Creation timestamp
   updated_at                                │ TIMESTAMPTZ                              │ DEFAULT CURRENT_TIMESTAMP                │ Update timestamp

  ### batches                                                                                                                                                                                          
                                                                                                                                                                                                       
  Student cohorts associated with a degree Programme.                                                                                                                                                  
                                                                                                                                                                                                       
   Column                                        │ Data Type                                     │ Constraints & Defaults                           │ Description
  ───────────────────────────────────────────────┼───────────────────────────────────────────────┼──────────────────────────────────────────────────┼──────────────────────────────────────────────────
   id                                            │ VARCHAR(50)                                   │ PRIMARY KEY                                      │ Unique batch ID (e.g., batch-cse-2022-26)
   programme_id                                  │ VARCHAR(50)                                   │ NOT NULL, FK -> programmes(id) ON DELETE CASCADE │ Associated programme
   programme_code                                │ VARCHAR(20)                                   │ NULL                                             │ Denormalized programme code
   programme_name                                │ VARCHAR(255)                                  │ NULL                                             │ Denormalized programme name
   duration_years                                │ INTEGER                                       │ NOT NULL DEFAULT 4                               │ Cohort duration
   name                                          │ VARCHAR(255)                                  │ NOT NULL                                         │ Cohort label (e.g., 2022-2026 Batch)
   start_year                                    │ INTEGER                                       │ NOT NULL                                         │ Inception year (e.g., 2022)
   end_year                                      │ INTEGER                                       │ NOT NULL                                         │ Graduation year (e.g., 2026)
   previous_batch_id                             │ VARCHAR(50)                                   │ FK -> batches(id) ON DELETE SET NULL             │ Preceding batch for continuous attainment trends
   year_level                                    │ VARCHAR(100)                                  │ NULL                                             │ Current academic year level (e.g., Final Year)
   status                                        │ VARCHAR(20)                                   │ NOT NULL DEFAULT 'ACTIVE'                        │ Batch lifecycle status
   created_at                                    │ TIMESTAMPTZ                                   │ DEFAULT CURRENT_TIMESTAMP                        │ Creation timestamp
   updated_at                                    │ TIMESTAMPTZ                                   │ DEFAULT CURRENT_TIMESTAMP                        │ Update timestamp
                                                                                                                                                                                                       
  • Check Constraints:                                                                                                                                                                                 
  chk_batch_year_range (end_year > start_year)                                                                                                                                                         
  chk_batch_duration (end_year - start_year = duration_years)                                                                                                                                          
  ──────

   status                                          │ VARCHAR(20)                                     │ NOT NULL DEFAULT 'ACTIVE'                      │ Status
   created_at                                      │ TIMESTAMPTZ                                     │ DEFAULT CURRENT_TIMESTAMP                      │ Creation timestamp

  • Check Constraints: chk_semester_number (semester_num >= 1)
